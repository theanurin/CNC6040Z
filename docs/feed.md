# Feed

## Оцинкована сталь

F = RPM * 2(F) * Chip load

Фреза d2mm 2F:

- Chip load Мінімум  (0.3% від D): 2мм * 0.3% = 0.006мм/зуб
- Chip load Максимум (0.5% від D): 2мм * 0.5% = 0.010мм/зуб
- Feed Мінімум:  4000 * 2 * 0.006 = 48мм/хв
- Feed Максимум: 4000 * 2 * 0.010 = 80мм/хв
- Feed Мінімум:  8000 * 2 * 0.006 = 96мм/хв
- Feed Максимум: 8000 * 2 * 0.010 = 160мм/хв
- Feed Мінімум:  10000 * 2 * 0.006 = 120мм/хв
- Feed Максимум: 10000 * 2 * 0.010 = 200мм/хв

Фреза d3mm 2F:

- Chip load Мінімум  (0.35% від D): 3мм * 0.35% = 0.010мм/зуб
- Chip load Максимум (0.60% від D): 3мм * 0.60% = 0.018мм/зуб
- Feed Мінімум:  6000 * 2 * 0.010 = 120мм/хв
- Feed Максимум: 6000 * 2 * 0.018 = 216мм/хв
- Feed Мінімум:  8000 * 2 * 0.010 = 160мм/хв
- Feed Максимум: 8000 * 2 * 0.018 = 288мм/хв
- Feed Мінімум:  10000 * 2 * 0.010 = 200мм/хв
- Feed Максимум: 10000 * 2 * 0.018 = 360мм/хв
