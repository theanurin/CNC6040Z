# Використання JSCut для CNC6040Z Milling Machine

## Особливості роботи з JSCut

Для розглядання особливостей роботи з JSCut візьмемо наступний вектор-квадрат розміром 10х10мм розташований по центру за допомогою зміщення viewBox ліворуч та вгору на 5мм

```svg
<?xml version="1.0" encoding="UTF-8"?>
<svg
    xmlns="http://www.w3.org/2000/svg"
    width="20mm"
    height="20mm"
    viewBox="-5 -5 20 20"
    fill="none" stroke="black" stroke-width="0.1"
>
    <path d="M 0 0 L 0 10 L 10 10 L 10 0 L 0 0 Z" />
</svg>
```

Дивись:

- [calibration-jscut.json](2026-05-20-cnc6040-svg-jscut/calibration-jscut.json)
- [calibration-jscut.svg](2026-05-20-cnc6040-svg-jscut/calibration-jscut.svg)

Так як в SVG мається зміщення початку координат (-5,5) в viewBox компенсувати це зміщення необхідно в Gcode Conversion -> X/Y Offset встановити в залежності від того в яку чверть планується фрезування:

| Чверть призначення        | X Offset | Y Offset |
| ------------------------- | -------- | -------- |
| Верхній правий кут (+, +) | -5       | 15       |
| Верхній лівий кут (-, +)  | -15      | 15       |
| Нижній лівий кут (-, -)   | -15      | 5        |
| Нижній правий кут (+, -)  | -5       | 5        |
