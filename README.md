# CNC-6040-Z

CNC Machine 6040Z Life Story

## Setup Development Environment

Note: This repository uses Git Large File Storage (Git LFS) to store large binary files.

```shell
git lfs install # required once per machine

cd CNC6040Z
git config --local core.hooksPath .githooks
git submodule update --init
```
